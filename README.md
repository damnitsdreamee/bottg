# Бот обращений к старостам — БИСО-03-25

Telegram-бот, через который студенты группы задают вопросы старостам. Вместо того чтобы писать каждому старосте в личку, студент пишет одному боту: вопрос попадает в общий чат старост, кто-то из них берёт его и отвечает, а ответ приходит студенту прямо в бота.

## Для чего он

- Все вопросы в одном месте — ничего не теряется в личных сообщениях
- Старосты видят, кто уже взял вопрос, и не отвечают на одно и то же вдвоём
- У каждого студента сохраняется своя история переписки

## Как это работает

1. Студент пишет боту в личку
2. Бот создаёт тикет и отправляет его в чат старост — в отдельную тему этого студента
3. Староста нажимает «Взять», потом «Ответить»
4. Ответ приходит студенту в бота
5. Когда вопрос решён — тикет закрывается (при необходимости его можно открыть заново)

## Функции

### Для студентов
- Вопрос отправляется обычным сообщением — без команд и меню
- После отправки приходит номер тикета
- Если тикет уже открыт, новые сообщения автоматически добавляются в него как дополнение

### Для старост
- Кнопки под каждым тикетом: 🙋 **Взять**, 💬 **Ответить**, ❌ **Закрыть**, 🔄 **Переоткрыть**
- В карточке тикета видно студента, статус, кто взял вопрос и когда он создан
- Статусы тикета: новый → в работе → закрыт
- Список всех открытых тикетов и тикетов конкретного старосты
- История переписки по любому тикету
- `/setname ID Имя` — задать студенту своё имя

## Плюшки

- **Отдельная тема на каждого студента.** Чат старост работает как форум: у каждого студента своя тема, где лежат все его вопросы и ответы.
- **Свои имена для студентов.** В Telegram студент может быть подписан как «котик», а у старост он будет «Матвейка». Тема переименовывается автоматически.
- **Медиа в обе стороны.** Фото, видео, голосовые, документы и GIF можно отправлять и в вопросе, и в ответе.
- **Антиспам.** Не чаще одного сообщения в 15 секунд (альбомы при этом не режутся).
- **Самовосстановление.** Если тему студента случайно удалили, бот сам создаст новую.
- **Ничего не пропадает.** Тикеты и переписка хранятся в базе SQLite и переживают перезапуск бота.

## Установка

Бот уже работает на хостинге — студентам ничего устанавливать не нужно, достаточно найти бота и нажать `/start`.

Если хочешь запустить свою копию:

1. Установи Python 3.10+ и зависимости:
   ```
   pip install aiogram aiosqlite
   ```
2. В начале файла заполни:
   - `BOT_TOKEN` — токен от @BotFather
   - `STAROSTA_CHAT_ID` — ID чата старост
   - `ADMIN_IDS` — Telegram ID старост
3. Чат старост должен быть группой с включёнными **темами**, а бот — админом с правом управлять темами.
4. Запусти:
   ```
   python "tgssupportbot v1.2.py"
   ```
